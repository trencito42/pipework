# Reference Prototypes

This directory contains design and interaction reference assets (such as `pipework-gemini.html`).

## Important Rules:
1. **Reference Only**: These files are NOT part of the Xcode application target and must never be shipped with the iOS app bundle.
2. **Native Implementation**: All production code for PIPEWORK is native Swift / SwiftUI / CoreGraphics / UIKit.
3. **No WebViews**: Never embed or port web frameworks. Use these references strictly to study visual proportions, board hierarchy, pipe layering, socket appearance, and tactile pacing.
